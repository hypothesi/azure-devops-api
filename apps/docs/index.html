@hypothesi/azure-devops-api

A typed Azure DevOps REST API client for browsers and Node.js, generated from the Azure DevOps OpenAPI documents.

  • API reference, with one document per API version
  • Compatibility: which entry point and API version to use with each Azure DevOps product

Install

npm install @hypothesi/azure-devops-api zod

Quick start

Import from the entry point for your product. /services is for Azure DevOps Services. /server-2022 is for Azure DevOps Server 2022. The compatibility page lists all entry points. 

import { createClient, wit } from '@hypothesi/azure-devops-api/services';

const ado = createClient({ organization: 'contoso', auth: { type: 'pat', token: process.env.AZURE_DEVOPS_PAT ?? '' } });

const workItem = await wit.workItemsGetWorkItem({ client: ado, path: { project: 'Web', id: 42 } });
